===========================
Welcome to Your Record Space
===========================

1. Uploading Files
   - Use the “+” or “Upload” button to add files.
   - Or simply drag and drop files from your computer.

2. Organizing Files
   - Create subfolders (“New Folder”) to group files.
   - You can move files by dragging them into folders.

3. Sharing Files
   - Right-click a file or folder → “Share”.
   - Copy the link or add people by email.

4. Mounted Files
   - Some files may appear automatically (mounted).
   - These come from connected systems and cannot be moved or deleted.

5. Review Process
   - During review, files are locked for editing.
   - You can still view and download them, but not change them.

6. Quick Tips
   - Use search (top bar) to quickly find files.
   - Sort by name, size, or modified date with the column headers.
   - Keep names clear and consistent for easier navigation.

--------------------------------
That’s it! You’re ready to begin.
